A make.fun entry for [The Funniest Toaster Error](https://make.fun/competitions/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) — write the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer.

## The entry

> E12: This bread has unionized. Toasting suspended pending negotiations.

71 characters, one line, deadpan appliance voice. The surprise isn't burnt bread — it's labour relations: the slice has organised, and the toaster is the middle manager caught between its owner and its workforce.

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt`. Deterministic — the same bytes on every run. No dependencies, no network.
